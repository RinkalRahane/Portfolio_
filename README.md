# Rinkal Rahane — Personal Developer Portfolio

> Minimalist editorial personal portfolio website engineered with semantic HTML5, modern vanilla CSS, responsive design, and accessible vanilla JavaScript.

## 👤 About Rinkal Rahane

- **Role:** B.Tech Student in Computer Science and Engineering
- **Specialization:** Artificial Intelligence and Machine Learning (AI & ML)
- **University:** Sanjivani University, Kopargaon
- **Key Interests:** Machine Learning, Natural Language Processing, Python, Frontend Development & Data Visualization

---

## 🚀 Live Sections & Features

1. **Header & Navigation:** Sticky navigation bar with frosted glass backdrop, responsive mobile hamburger drawer, and seamless light/dark theme toggle.
2. **Hero Section:** Concise introduction, direct links to download resume and explore projects, social connections (GitHub & LinkedIn), and high-resolution portrait showcase.
3. **About Me:** Professional background, university affiliation, and focus areas without exaggerated claims.
4. **Skills & Toolkit:** Clean category tags spanning Programming, Frontend, Design & Prototyping, and Analytics & Interpersonal skills.
5. **Projects Showcase:**
   - **Expense Tracker:** Personal budget management web application with browser storage persistence.
   - **Matplotlib Data Visualization:** Statistical exploratory analysis and custom charts using Python.
   - **Resume Checker using NLP:** Intelligent text processing application analyzing resumes against job descriptions.
   - **Personal Portfolio:** Accessible, editorial developer portfolio.
6. **Education:** Verified academic information at Sanjivani University, Kopargaon.
7. **Contact:** Direct email link (`mailto:`), LinkedIn, and GitHub profiles.

---

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5 (W3C compliant, full accessibility and SEO metadata)
- **Styling:** Vanilla CSS3 with CSS Custom Properties (Theme tokens, clamp typography, flexbox, CSS Grid)
- **Interactions:** Vanilla JavaScript (ES6+) with zero external dependencies
- **Typography:** Inter (Google Fonts)

## 💻 Local Preview & Usage

Simply open `index.html` in any modern web browser or serve via:
```bash
# Python 3
python -m http.server 8000

# or Node.js / npx
npx serve .
```
